# Koku-G-nl-

Mobil uyumlu, istemci tarafında çalışan bir **Scent Journal (Koku Günlüğü)** prototipi.

## Özellikler
- Koku/parfüm deneyimi/koku hafızası kaydı oluşturma
- Alanlar: konum adı, enlem-boylam, tarih, duygu durumu, koku notaları, puanlama
- Kayıtları yerel depoda saklama (`localStorage`)
- Mekan bazlı koku haritası (enlem-boylam pinleri)
- Arama ve filtreleme (metin, duygu, minimum puan, tarih aralığı)
- Koku istatistikleri (toplam kayıt, ortalama puan, en sık duygu/not)

## Çalıştırma
Bu proje ek bağımlılık gerektirmez.

1. `/home/runner/work/Koku-G-nl-/Koku-G-nl-/index.html` dosyasını tarayıcıda açın.
2. Form ile kayıt ekleyin.
3. Filtrelerle arama yapın, harita ve istatistikleri takip edin.
